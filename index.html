What it checks

The signals behind every score.

Message wording

A text model trained to recognise phrasing typical of phishing and scam messages.

Link structure

Length, hyphens, subdomains, IP addresses, HTTPS, and unusual domain endings.

Lookalike domains

Links that mention a known brand but belong to a different domain, or swap a digit for a letter.

Pressure tactics

Urgent deadlines, account-block threats, prize bait, and requests for OTPs or passwords.

Stay safe

Habits that protect you even without a tool.

  • Banks never ask for your OTP, PIN, or password by message or call.
  • Type the website address yourself instead of tapping a link in a message.
  • Be wary of deadlines like "within 24 hours" or "blocked today".
  • Check the full domain, not just the brand name inside it.
  • If unsure, contact the company using the number on its official website.

FAQ

Does PhishGuard open the links I paste?

No. Links are analysed as text only, so nothing is visited.

Is my message stored?

It is processed to produce the result. A message is saved only when you click "Mark as wrong", and then it is written to a feedback file for retraining.

How accurate is it?

Use it as a second opinion, not a guarantee. Some real messages can be flagged by mistake and some scams can slip through, which is why every result shows its reasons.

What should I do if the result is wrong?

Click "Mark as wrong". The correction is saved so the models can be improved.
